# Event calendar

## Rules

- When adding a month, create `<YYYY-MM>.md` and keep only dated event rows below the rules link.
- When registering an event, record its type, UTC time, source link, and registration date. Use an official calendar or event record for the time; do not add a row with an unverified time.
- When entering an event by hand, mark it `manual`.
- When displaying Beijing time, derive UTC+8 from the row at use time.
- Types: `unlock`, `expiry`, `release`, `deadline`, `upgrade`.
