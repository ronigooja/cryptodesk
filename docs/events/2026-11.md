# Events 2026-11

Event calendar for this month. Add new months as new files.

## Rules

- When adding an event, give type, UTC time, source link, and the date it was registered.
- When an event was entered by hand (no API), mark `manual`.
- Unlock sizes from web pages are as shown on the page; they were not obtained from an API.
- Times in the Time column are UTC. Beijing time (UTC+8) is derived at use time.
- Types: `unlock`, `expiry`, `release`, `deadline`, `upgrade`.
